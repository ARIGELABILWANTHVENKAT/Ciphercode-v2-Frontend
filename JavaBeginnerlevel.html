📘 Unit 1: Java Fundamentals

Weeks 1-4

1.1 Introduction to Java & JVM

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It follows the principle of "Write Once, Run Anywhere" (WORA), meaning compiled Java code can run on all platforms that support Java without needing recompilation.

🔹 Key Components of Java Platform:
  • JDK (Java Development Kit): Includes JRE + development tools (compiler, debugger, etc.).
  • JRE (Java Runtime Environment): Provides libraries and JVM to run Java applications.
  • JVM (Java Virtual Machine): Executes bytecode. It provides memory management, garbage collection, and security.
🔹 How Java Code Executes:
  1. Source code (.java) → Compiled by javac → Bytecode (.class).
  2. Bytecode is interpreted by JVM or compiled Just-In-Time (JIT) to native machine code.
// Hello World Program public class HelloWorld { public static void main(String[] args) { System.out.println("Hello, World!"); } }

1.2 Data Types & Variables

Java is a strongly typed language, meaning every variable must have a declared type. Data types define the size and type of values that can be stored.

🔹 Primitive Data Types (8 types):
  • byte: 8-bit signed, range -128 to 127.
  • short: 16-bit signed, range -32,768 to 32,767.
  • int: 32-bit signed, range -2³¹ to 2³¹-1 (most common).
  • long: 64-bit signed, use 'L' suffix (e.g., 100L).
  • float: 32-bit floating point, use 'f' suffix (e.g., 3.14f).
  • double: 64-bit floating point (default for decimals).
  • char: 16-bit Unicode character (single quotes).
  • boolean: true or false.
🔹 Type Conversion:
  • Implicit (Widening): byte → short → int → long → float → double (automatic).
  • Explicit (Narrowing): double → float → long → int → ... (requires casting).
// Variable Declaration & Type Conversion int age = 25; double salary = 55000.75; char grade = 'A'; boolean isActive = true; // Implicit conversion long bigNumber = age; // int to long // Explicit casting float pi = (float) 3.14159;

1.3 Operators & Expressions

Operators perform operations on variables and values. Java supports various types of operators.

🔹 Types of Operators:
  • Arithmetic: +, -, *, /, %, ++, --
  • Relational: ==, !=, >, <, >=, <=
  • Logical: &&, ||, !
  • Bitwise: &, |, ^, ~, <<, >>
  • Assignment: =, +=, -=, *=, /=
🔹 Operator Precedence:

Parentheses have the highest precedence, followed by multiplication/division, then addition/subtraction.

// Operators Examples int a = 10, b = 3; System.out.println(a + b); // 13 System.out.println(a - b); // 7 System.out.println(a * b); // 30 System.out.println(a / b); // 3 (integer division) System.out.println(a % b); // 1 (remainder) // Relational and Logical System.out.println(a > b); // true System.out.println(a < b); // false System.out.println(a == b); // false System.out.println(a > 5 && b < 5); // true

1.4 Control Statements (if, switch)

Control statements allow you to make decisions in your code based on conditions.

🔹 if-else Statement:
  • if (condition) { // code }
  • if (condition) { ... } else { ... }
  • if (condition1) { ... } else if (condition2) { ... } else { ... }
🔹 switch Statement:

Switch is used when you have multiple conditions based on a single variable.

// if-else Example int marks = 85; if (marks >= 90) { System.out.println("A+"); } else if (marks >= 80) { System.out.println("A"); } else if (marks >= 70) { System.out.println("B"); } else { System.out.println("Needs Improvement"); } // Switch Example char grade = 'A'; switch (grade) { case 'A': System.out.println("Excellent!"); break; case 'B': System.out.println("Good!"); break; default: System.out.println("Keep working!"); }

1.5 Loops (for, while, do-while)

Loops execute a block of code repeatedly based on a condition.

🔹 for Loop:

for (initialization; condition; increment) { // code }

🔹 while Loop:

while (condition) { // code }

🔹 do-while Loop:

do { // code } while (condition); — executes at least once.

// for Loop for (int i = 1; i <= 5; i++) { System.out.println("Count: " + i); } // while Loop int j = 1; while (j <= 5) { System.out.println("While: " + j); j++; } // do-while Loop int k = 1; do { System.out.println("Do-while: " + k); k++; } while (k <= 5);

2.1 Classes & Objects

Java is an object-oriented language. Everything revolves around classes (blueprints) and objects (instances).

🔹 Class:

A class is a blueprint that defines the properties (fields) and behaviours (methods) of an object.

🔹 Object:

An object is an instance of a class created using the new keyword.

// Class Definition class Student { // Fields String name; int age; double gpa; // Method void displayInfo() { System.out.println("Name: " + name); System.out.println("Age: " + age); System.out.println("GPA: " + gpa); } } // Creating Objects public class Main { public static void main(String[] args) { Student s1 = new Student(); s1.name = "Alice"; s1.age = 20; s1.gpa = 3.8; s1.displayInfo(); } }

2.2 Constructors

Constructors are special methods that initialize an object when it is created. They have the same name as the class and no return type.

🔹 Types of Constructors:
  • Default Constructor: Provided by Java if no constructor is defined.
  • Parameterized Constructor: Accepts parameters to initialize fields.
  • Copy Constructor: Creates a new object by copying another object.
// Parameterized Constructor class Student { String name; int age; // Constructor Student(String n, int a) { name = n; age = a; } void display() { System.out.println(name + ", " + age); } } // Usage Student s1 = new Student("Bob", 22); s1.display();

2.3 Inheritance

Inheritance allows a class to inherit properties and methods from another class. It promotes code reusability.

🔹 Key Terms:
  • Superclass (Parent): The class being inherited from.
  • Subclass (Child): The class that inherits.
  • extends: Keyword used for inheritance.
  • super: References the parent class.
// Inheritance Example class Animal { void eat() { System.out.println("Animal eats"); } } class Dog extends Animal { void bark() { System.out.println("Dog barks"); } } // Usage Dog d = new Dog(); d.eat(); // Inherited method d.bark(); // Own method

2.4 Polymorphism

Polymorphism means "many forms". It allows one interface to be used for a general class of actions.

🔹 Compile-time Polymorphism (Method Overloading):

Multiple methods with the same name but different parameters.

🔹 Runtime Polymorphism (Method Overriding):

A subclass provides a specific implementation of a method already defined in its superclass.

// Method Overloading class MathUtils { int add(int a, int b) { return a + b; } int add(int a, int b, int c) { return a + b + c; } double add(double a, double b) { return a + b; } } // Method Overriding class Animal { void sound() { System.out.println("Animal sound"); } } class Cat extends Animal { void sound() { System.out.println("Meow"); } }

✏️ Practice Questions

2.5 Abstraction & Interfaces

Abstraction hides implementation details and shows only essential features. Java provides abstract classes and interfaces.

🔹 Abstract Class:

A class that cannot be instantiated and may contain abstract methods (methods without a body).

🔹 Interface:

A completely abstract type that defines a contract for classes to implement.

// Abstract Class abstract class Shape { abstract void draw(); } // Interface interface Drawable { void draw(); } // Implementation class Circle extends Shape implements Drawable { void draw() { System.out.println("Drawing Circle"); } }

An array is a container object that holds a fixed number of values of a single type.

🔹 Declaration & Initialization:

  • int[] numbers = {1, 2, 3, 4, 5};
🔹 Common Operations:

// Array Example int[] marks = {85, 90, 78, 92, 88}; int sum = 0; for (int i = 0; i < marks.length; i++) { sum += marks[i]; } double average = (double) sum / marks.length; System.out.println("Average: " + average);

3.3 String Class Methods

Strings in Java are immutable objects. The String class provides many useful methods.

🔹 Common Methods:
  • length() → returns the number of characters.
  • charAt(index) → returns the character at a specific index.
  • substring(start, end) → extracts a part of the string.
  • toUpperCase(), toLowerCase() → convert case.
  • trim() → removes leading/trailing spaces.
  • replace(old, new) → replaces characters.
  • split(regex) → splits the string into an array.
  • equals(), equalsIgnoreCase() → compare strings.
// String Methods Example String str = " Hello, World! "; System.out.println(str.length()); // 15 System.out.println(str.trim()); // "Hello, World!" System.out.println(str.toUpperCase()); // " HELLO, WORLD! " System.out.println(str.substring(0, 5)); // " Hell" System.out.println(str.contains("World")); // true String[] parts = str.trim().split(","); System.out.println(parts[0]); // "Hello" System.out.println(parts[1]); // " World!"

3.4 StringBuffer & StringBuilder

Unlike String, StringBuffer and StringBuilder are mutable and more efficient when performing many modifications.

🔹 Differences:
  • StringBuffer: Thread-safe (synchronized), slower.
  • StringBuilder: Not thread-safe, faster.
🔹 Common Methods:
  • append() → adds text to the end.
  • insert() → inserts text at a position.
  • delete() → removes characters.
  • reverse() → reverses the sequence.
// StringBuilder Example StringBuilder sb = new StringBuilder("Hello"); sb.append(" World"); sb.insert(5, " Java"); sb.delete(5, 10); System.out.println(sb.toString()); // "HelloWorld"

3.5 Wrapper Classes

Wrapper classes convert primitive types into objects. They are used in collections and for utility methods.

🔹 Primitive ↔ Wrapper:
  • byte → Byte
  • short → Short
  • int → Integer
  • long → Long
  • float → Float
  • double → Double
  • char → Character
  • boolean → Boolean
🔹 Autoboxing & Unboxing:

Autoboxing is the automatic conversion of primitive to wrapper, and unboxing is the reverse.

// Wrapper Class Example Integer num = 10; // Autoboxing int value = num; // Unboxing // Parsing int parsed = Integer.parseInt("123"); double d = Double.parseDouble("3.14"); // Utility methods System.out.println(Integer.MAX_VALUE); System.out.println(Integer.toBinaryString(10));

4.1 Exception Handling (try-catch)

Exception handling is used to manage runtime errors and maintain normal program flow.

🔹 Key Concepts:
  • try: Block where exceptions may occur.
  • catch: Block that handles specific exceptions.
  • finally: Block that executes regardless of exception (used for cleanup).
  • throws: Declares that a method might throw an exception.
// Exception Handling Example try { int result = 10 / 0; // ArithmeticException System.out.println(result); } catch (ArithmeticException e) { System.out.println("Cannot divide by zero!"); } finally { System.out.println("This always runs"); }

4.3 File I/O (FileReader, FileWriter)

Java provides classes for reading and writing files using character streams.

🔹 FileWriter:

Used to write characters to a file.

🔹 FileReader:

4.4 Serialization

Serialization converts an object into a byte stream, allowing it to be saved to a file or transferred over a network.

🔹 Key Steps:
  • Make the class implement Serializable.
  • Use ObjectOutputStream to write objects.
  • Use ObjectInputStream to read objects.
  • transient keyword prevents a field from being serialized.
// Serializable Class import java.io.*; class Person implements Serializable { String name; int age; transient String password; // Won't be serialized Person(String name, int age, String password) { this.name = name; this.age = age; this.password = password; } } // Write object Person p = new Person("Alice", 25, "secret"); try (ObjectOutputStream out = new ObjectOutputStream( new FileOutputStream("person.ser"))) { out.writeObject(p); } // Read object try (ObjectInputStream in = new ObjectInputStream( new FileInputStream("person.ser"))) { Person read = (Person) in.readObject(); System.out.println(read.name + ", " + read.age); }

4.5 Buffered Streams

Buffered streams improve performance by reducing the number of I/O operations.

🔹 Buffered I/O Classes:
  • BufferedReader → reads text from an input stream efficiently.
  • BufferedWriter → writes text to an output stream efficiently.
// Using BufferedReader try (BufferedReader br = new BufferedReader( new FileReader("input.txt"))) { String line; while ((line = br.readLine()) != null) { System.out.println(line); } } // Using BufferedWriter try (BufferedWriter bw = new BufferedWriter( new FileWriter("output.txt"))) { bw.write("Hello, Buffered!"); bw.newLine(); bw.write("Second line"); }
