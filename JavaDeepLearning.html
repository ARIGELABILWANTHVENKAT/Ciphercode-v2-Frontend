🔬 1.1 What is Deep Learning?

Deep Learning is a subset of machine learning that uses neural networks with multiple layers (hence "deep") to learn hierarchical representations of data.

📌 Key Concepts

  • Neural Network: Computational model inspired by biological neurons
  • Layers: Input, Hidden, and Output layers
  • Weights & Biases: Parameters learned during training
  • Activation Functions: Introduce non-linearity (ReLU, Sigmoid, Tanh)
  • Backpropagation: Algorithm to compute gradients
  • Gradient Descent: Optimization algorithm to minimize loss
Neuron Mathematics 
// A single neuron computes:
// output = activation(Σ(weight_i * input_i) + bias)

import java.util.Arrays;

public class Neuron {
    private double[] weights;
    private double bias;
    
    public Neuron(int inputSize) {
        weights = new double[inputSize];
        bias = 0.0;
        // Initialize weights randomly
        for (int i = 0; i < inputSize; i++) {
            weights[i] = Math.random() * 2 - 1;
        }
    }
    
    public double activate(double[] inputs) {
        double sum = bias;
        for (int i = 0; i < inputs.length; i++) {
            sum += weights[i] * inputs[i];
        }
        return relu(sum);  // ReLU activation
    }
    
    private double relu(double x) {
        return Math.max(0, x);
    }
}
Activation Functions 
public class Activations {
    
    // ReLU: f(x) = max(0, x)
    public static double relu(double x) {
        return Math.max(0, x);
    }
    
    // Sigmoid: f(x) = 1 / (1 + e^(-x))
    public static double sigmoid(double x) {
        return 1 / (1 + Math.exp(-x));
    }
    
    // Tanh: f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
    public static double tanh(double x) {
        return Math.tanh(x);
    }
    
    // Softmax: converts logits to probabilities
    public static double[] softmax(double[] logits) {
        double[] exp = new double[logits.length];
        double sum = 0;
        for (int i = 0; i < logits.length; i++) {
            exp[i] = Math.exp(logits[i]);
            sum += exp[i];
        }
        for (int i = 0; i < exp.length; i++) {
            exp[i] /= sum;
        }
        return exp;
    }
    
    // Derivatives for backpropagation
    public static double reluDerivative(double x) {
        return x > 0 ? 1 : 0;
    }
    
    public static double sigmoidDerivative(double x) {
        return x * (1 - x);
    }
}

⚠️ Common Pitfalls

Vanishing Gradients: Sigmoid/Tanh can cause gradients to become very small in deep networks. Use ReLU or its variants (LeakyReLU, ELU) for hidden layers.

📊 1.2 Loss Functions

Loss functions measure how far the model's predictions are from the actual values.

Common Loss Functions 
public class LossFunctions {
    
    // Mean Squared Error (Regression)
    public static double mse(double[] actual, double[] predicted) {
        double sum = 0;
        for (int i = 0; i < actual.length; i++) {
            sum += Math.pow(actual[i] - predicted[i], 2);
        }
        return sum / actual.length;
    }
    
    // Cross-Entropy Loss (Classification)
    public static double crossEntropy(double[] actual, double[] predicted) {
        double loss = 0;
        for (int i = 0; i < actual.length; i++) {
            loss -= actual[i] * Math.log(predicted[i] + 1e-15);
        }
        return loss;
    }
    
    // Binary Cross-Entropy (Binary Classification)
    public static double binaryCrossEntropy(double actual, double predicted) {
        return -(actual * Math.log(predicted + 1e-15) + 
                (1 - actual) * Math.log(1 - predicted + 1e-15));
    }
    
    // Categorical Cross-Entropy (Multi-class)
    public static double categoricalCrossEntropy(int actual, double[] predicted) {
        return -Math.log(predicted[actual] + 1e-15);
    }
}

⚡ 1.3 Optimization Algorithms

Optimizers update model weights to minimize the loss function.

SGD & Adam Optimizer 
public class SGDOptimizer {
    private double learningRate;
    
    public SGDOptimizer(double learningRate) {
        this.learningRate = learningRate;
    }
    
    public double[] update(double[] weights, double[] gradients) {
        double[] newWeights = new double[weights.length];
        for (int i = 0; i < weights.length; i++) {
            newWeights[i] = weights[i] - learningRate * gradients[i];
        }
        return newWeights;
    }
}

public class AdamOptimizer {
    private double learningRate, beta1, beta2, epsilon;
    private double[] m, v;  // First & second moment estimates
    private int t;  // Time step
    
    public AdamOptimizer(int paramSize) {
        this.learningRate = 0.001;
        this.beta1 = 0.9;
        this.beta2 = 0.999;
        this.epsilon = 1e-8;
        m = new double[paramSize];
        v = new double[paramSize];
        t = 0;
    }
    
    public double[] update(double[] weights, double[] gradients) {
        t++;
        double[] newWeights = new double[weights.length];
        
        for (int i = 0; i < weights.length; i++) {
            // Update biased first moment estimate
            m[i] = beta1 * m[i] + (1 - beta1) * gradients[i];
            // Update biased second raw moment estimate
            v[i] = beta2 * v[i] + (1 - beta2) * gradients[i] * gradients[i];
            // Bias-corrected estimates
            double mHat = m[i] / (1 - Math.pow(beta1, t));
            double vHat = v[i] / (1 - Math.pow(beta2, t));
            // Update weights
            newWeights[i] = weights[i] - learningRate * mHat / (Math.sqrt(vHat) + epsilon);
        }
        return newWeights;
    }
}

🔄 1.4 Backpropagation Algorithm

Backpropagation computes gradients of the loss with respect to each weight using the chain rule.

Simple Backprop Example 
public class SimpleNeuralNetwork {
    private double[] inputLayer, hiddenLayer, outputLayer;
    private double[][] weightsIH, weightsHO;  // Input-Hidden, Hidden-Output
    private double[] biasH, biasO;
    private double learningRate = 0.1;
    
    public void forward(double[] input) {
        inputLayer = input;
        
        // Hidden layer computation
        for (int j = 0; j < hiddenLayer.length; j++) {
            double sum = biasH[j];
            for (int i = 0; i < input.length; i++) {
                sum += input[i] * weightsIH[i][j];
            }
            hiddenLayer[j] = sigmoid(sum);
        }
        
        // Output layer computation
        for (int j = 0; j < outputLayer.length; j++) {
            double sum = biasO[j];
            for (int i = 0; i < hiddenLayer.length; i++) {
                sum += hiddenLayer[i] * weightsHO[i][j];
            }
            outputLayer[j] = sigmoid(sum);
        }
    }
    
    public void backward(double[] target) {
        // Output layer errors
        double[] outputErrors = new double[outputLayer.length];
        for (int i = 0; i < outputLayer.length; i++) {
            outputErrors[i] = (target[i] - outputLayer[i]) * 
                              sigmoidDerivative(outputLayer[i]);
        }
        
        // Hidden layer errors
        double[] hiddenErrors = new double[hiddenLayer.length];
        for (int i = 0; i < hiddenLayer.length; i++) {
            double error = 0;
            for (int j = 0; j < outputLayer.length; j++) {
                error += outputErrors[j] * weightsHO[i][j];
            }
            hiddenErrors[i] = error * sigmoidDerivative(hiddenLayer[i]);
        }
        
        // Update weights (Hidden-Output)
        for (int i = 0; i < hiddenLayer.length; i++) {
            for (int j = 0; j < outputLayer.length; j++) {
                weightsHO[i][j] += learningRate * outputErrors[j] * hiddenLayer[i];
            }
        }
        
        // Update weights (Input-Hidden)
        for (int i = 0; i < inputLayer.length; i++) {
            for (int j = 0; j < hiddenLayer.length; j++) {
                weightsIH[i][j] += learningRate * hiddenErrors[j] * inputLayer[i];
            }
        }
    }
}

🏗️ 2.2 Building Neural Networks with DL4J

Multi-Layer Perceptron (MLP) 
import org.deeplearning4j.nn.conf.MultiLayerConfiguration;
import org.deeplearning4j.nn.conf.NeuralNetConfiguration;
import org.deeplearning4j.nn.conf.layers.DenseLayer;
import org.deeplearning4j.nn.conf.layers.OutputLayer;
import org.deeplearning4j.nn.multilayer.MultiLayerNetwork;
import org.nd4j.linalg.activations.Activation;
import org.nd4j.linalg.learning.config.Adam;
import org.nd4j.linalg.lossfunctions.LossFunctions;

public class MLPClassifier {
    
    public static MultiLayerNetwork buildModel(int inputSize, int numClasses) {
        
        MultiLayerConfiguration config = new NeuralNetConfiguration.Builder()
            .seed(42)
            .updater(new Adam(0.001))
            .weightInit(new Xavier())
            .list()
            
            // Hidden Layer 1
            .layer(0, new DenseLayer.Builder()
                .nIn(inputSize)
                .nOut(128)
                .activation(Activation.RELU)
                .dropOut(0.3)
                .build())
            
            // Hidden Layer 2
            .layer(1, new DenseLayer.Builder()
                .nOut(64)
                .activation(Activation.RELU)
                .dropOut(0.2)
                .build())
            
            // Hidden Layer 3
            .layer(2, new DenseLayer.Builder()
                .nOut(32)
                .activation(Activation.RELU)
                .build())
            
            // Output Layer
            .layer(3, new OutputLayer.Builder(
                    LossFunctions.LossFunction.NEGATIVELOGLIKELIHOOD)
                .nOut(numClasses)
                .activation(Activation.SOFTMAX)
                .build())
            
            .build();
        
        MultiLayerNetwork model = new MultiLayerNetwork(config);
        model.init();
        return model;
    }
}
Training the Model 
import org.nd4j.linalg.dataset.api.iterator.DataSetIterator;
import org.nd4j.linalg.dataset.api.preprocessor.NormalizerStandardize;

public class ModelTrainer {
    
    public static void train(MultiLayerNetwork model, 
                             DataSetIterator trainData,
                             DataSetIterator testData,
                             int epochs) {
        
        // Normalize data
        NormalizerStandardize normalizer = new NormalizerStandardize();
        normalizer.fit(trainData);
        trainData.setPreProcessor(normalizer);
        testData.setPreProcessor(normalizer);
        
        System.out.println("Starting training...");
        
        for (int i = 0; i < epochs; i++) {
            model.fit(trainData);
            trainData.reset();
            
            // Evaluate after each epoch
            Evaluation eval = model.evaluate(testData);
            testData.reset();
            
            System.out.printf("Epoch %d/%d - Accuracy: %.4f, F1: %.4f%n",
                i + 1, epochs, eval.accuracy(), eval.f1());
        }
    }
}

🖼️ 2.3 CNN for Image Classification

Convolutional Neural Network 
import org.deeplearning4j.nn.conf.layers.ConvolutionLayer;
import org.deeplearning4j.nn.conf.layers.SubsamplingLayer;
import org.deeplearning4j.nn.conf.layers.GlobalPoolingLayer;

public class CNNImageClassifier {
    
    public static MultiLayerNetwork buildCNN(int channels, int numClasses) {
        
        MultiLayerConfiguration config = new NeuralNetConfiguration.Builder()
            .seed(42)
            .updater(new Adam(0.001))
            .weightInit(new Xavier())
            .list()
            
            // Conv Layer 1: 32 filters, 3x3 kernel
            .layer(0, new ConvolutionLayer.Builder()
                .kernelSize(3, 3)
                .stride(1, 1)
                .nIn(channels)
                .nOut(32)
                .activation(Activation.RELU)
                .build())
            
            // Max Pool 1: 2x2
            .layer(1, new SubsamplingLayer.Builder()
                .poolingType(SubsamplingLayer.PoolingType.MAX)
                .kernelSize(2, 2)
                .stride(2, 2)
                .build())
            
            // Conv Layer 2: 64 filters
            .layer(2, new ConvolutionLayer.Builder()
                .kernelSize(3, 3)
                .nOut(64)
                .activation(Activation.RELU)
                .build())
            
            .layer(3, new SubsamplingLayer.Builder()
                .kernelSize(2, 2)
                .build())
            
            // Conv Layer 3: 128 filters
            .layer(4, new ConvolutionLayer.Builder()
                .kernelSize(3, 3)
                .nOut(128)
                .activation(Activation.RELU)
                .build())
            
            // Global Average Pooling
            .layer(5, new GlobalPoolingLayer.Builder()
                .poolingType(SubsamplingLayer.PoolingType.AVG)
                .build())
            
            // Dense Layer
            .layer(6, new DenseLayer.Builder()
                .nOut(128)
                .activation(Activation.RELU)
                .dropOut(0.5)
                .build())
            
            // Output Layer
            .layer(7, new OutputLayer.Builder(
                    LossFunctions.LossFunction.NEGATIVELOGLIKELIHOOD)
                .nOut(numClasses)
                .activation(Activation.SOFTMAX)
                .build())
            
            .build();
        
        MultiLayerNetwork model = new MultiLayerNetwork(config);
        model.init();
        return model;
    }
}

public class LSTMTextClassifier {
    
    public static MultiLayerNetwork buildLSTM(
            int vocabSize, int embeddingSize, int numClasses) {

            .seed(42)
            .updater(new Adam(0.001))
            .list()

                .nIn(vocabSize + 1)
                .nOut(embeddingSize)
                .inputLength(-1)  // Variable length
                .build())
            
            // LSTM Layer 1
            .layer(1, new LSTM.Builder()
                .nIn(embeddingSize)
                .nOut(128)
                .activation(Activation.TANH)
                .build())
            
            // LSTM Layer 2
            .layer(2, new LSTM.Builder()
                .nOut(64)
                .activation(Activation.TANH)
                .build())
            
            // RNN Output
            .layer(3, new RnnOutputLayer.Builder(
                    LossFunctions.LossFunction.NEGATIVELOGLIKELIHOOD)
                .nOut(numClasses)
                .activation(Activation.SOFTMAX)
                .build())
            
            .build();
        
        return new MultiLayerNetwork(config);
    }
}

📈 4.2 TensorFlow Java Example

Linear Regression with TF Java 
import org.tensorflow.*;
import org.tensorflow.ndarray.*;
import org.tensorflow.types.*;

public class TFLinearRegression {
    
    public static void main(String[] args) {
        try (Graph g = new Graph()) {
            
            // Define variables
            try (Scope scope = new Scope(g).withName("train")) {
                // Weight variable
                Output<TFloat32> W = tf.variable(
                    scope.makeSubScope("W"),
                    Shape.of(1, 1),
                    TFloat32.class
                );
                
                // Bias variable
                Output<TFloat32> b = tf.variable(
                    scope.makeSubScope("b"),
                    Shape.of(1),
                    TFloat32.class
                );
                
                // Input placeholder
                Output<TFloat32> x = tf.placeholder(TFloat32.class, 
                    Shape.of(-1, 1), "input");
                
                // Model: y = W*x + b
                Output<TFloat32> y = tf.math.add(
                    tf.linalg.matMul(x, W), b);
                
                // Loss: MSE
                Output<TFloat32> yTrue = tf.placeholder(TFloat32.class, 
                    Shape.of(-1, 1), "label");
                Output<TFloat32> loss = tf.math.mean(
                    tf.math.square(tf.math.sub(y, yTrue)));
                
                // Training with gradient descent
                Output<TFloat32> optimizer = tf.train.gradientDescent(0.01f)
                    .minimize(loss);
                
                // Run training
                try (Session s = new Session(g)) {
                    s.runner().addTarget(optimizer).run();
                    System.out.println("Training complete!");
                }
            }
        }
    }
}

🌐 5.2 Transformer Architecture

Self-Attention Mechanism 
public class SelfAttention {
    
    public static INDArray scaledDotProductAttention(
            INDArray Q, INDArray K, INDArray V) {
        
        int dK = K.size(2);
        
        // Attention = softmax(Q * K^T / sqrt(dK)) * V
        INDArray scores = Nd4j.linalg.tensorMul(Q, K.transpose(0, 2, 1));
        scores = scores.div(Math.sqrt(dK));
        INDArray attentionWeights = Nd4j.softmax(scores, -1);
        
        return Nd4j.linalg.tensorMul(attentionWeights, V);
    }
    
    public static INDArray[] multiHeadAttention(
            INDArray input, int numHeads, int dModel) {
        
        int dK = dModel / numHeads;
        INDArray[] heads = new INDArray[numHeads];
        
        for (int i = 0; i < numHeads; i++) {
            // Project Q, K, V for each head
            INDArray Q = linearProjection(input, dK);
            INDArray K = linearProjection(input, dK);
            INDArray V = linearProjection(input, dK);
            
            heads[i] = scaledDotProductAttention(Q, K, V);
        }
        
        // Concatenate heads and project
        INDArray concatenated = Nd4j.concat(2, heads);
        return new INDArray[]{concatenated};
    }
}
