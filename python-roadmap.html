🧠 DAILY ROUTINE

1

Learn (30 mins)

Watch 1 short YouTube video or read documentation on today's topic.

2

Type (30 mins)

DO NOT COPY-PASTE. Manually type code examples to build muscle memory.

3

Practice (20 mins)

Solve 1-2 Easy-level problems on HackerRank or LeetCode.

4

Debug

When you get errors, read the red text carefully. Google it. This is how real developers learn!

🎯 GOLDEN RULES FOR THE 30 DAYS

1️⃣ Don't skip a day. Missing one day breaks the habit. 15 minutes is better than 0.
2️⃣ Print everything. Use print() constantly to see what your code is doing.
3️⃣ Break problems down. Write steps in plain English first, then translate to Python.
4️⃣ Build public. Push your Day 30 project to GitHub. Employers love to see the journey!
